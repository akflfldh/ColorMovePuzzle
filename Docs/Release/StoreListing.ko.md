# Google Play 스토어 문구·이미지 준비 초안

실제 등록·게시하지 않았습니다. 앱 이름과 아래 문구는 소유자 검토용 후보입니다. 기존 게임 UI를 변경하지 않았습니다.

## 앱 이름 후보

**Color Move Puzzle**

현재 프로젝트명은 ColorMovePuzzle이며 게임 화면에는 COLOR MOVE/COLOR SLIDE 표기가 있습니다. 스토어 최종 이름·상표 사용 가능 여부·브랜드 일관성은 소유자가 결정해야 합니다.

## 짧은 소개 후보

색상 타일을 빈칸으로 밀어 목표 패턴을 완성하세요. 세 가지 격자와 90개 퍼즐에 도전해 보세요.

## 자세한 소개 후보

정사각형 색상 타일을 빈칸으로 움직여 화면 위의 목표 패턴과 같은 배열을 만들어 보세요.

상하좌우로 인접한 빈칸으로 한 칸씩 이동할 수 있습니다. 이동 방향이 하나일 때는 탭하고, 여러 빈칸 중 하나를 고를 때는 원하는 방향으로 스와이프하세요.

- 3×3, 4×4, 5×5의 세 가지 격자
- 각 모드 30개씩 총 90개 스테이지
- 스테이지 클리어에 따른 다음 퍼즐 해금
- 이동한 배치와 이동 횟수 자동 저장
- 이어하기로 진행 중이던 퍼즐 복원
- 재시작과 모드별 독립 진행 기록

앱에는 광고가 포함됩니다. 광고·개인정보 관련 동작은 지역과 설정에 따라 달라질 수 있습니다.

힌트·별점·추가 스테이지·구매·새 오디오·계정 클라우드 저장처럼 구현되지 않은 기능은 문구에 넣지 않았습니다. '데이터 수집 없음', '광고 없음', '완전한 오프라인 앱'이라고 표시하지 않습니다.

## 이미지 준비 목록

| 항목 | 준비 기준 | 현재 상태 |
|---|---|---|
| Google Play 앱 아이콘 | 512×512, 32-bit PNG, 1024KB 이하 | 미제작 |
| Android launcher/adaptive 아이콘 | Android용 foreground/background 및 필요한 크기 | 현재 Android 사용자 지정 아이콘 참조가 모두 비어 있음. Unity 기본 아이콘으로 출시하지 않도록 준비 필요 |
| Feature graphic | 1024×500, JPEG 또는 alpha 없는 24-bit PNG | 미제작 |
| 스마트폰 스크린샷 | 최소 2장. 권장: 1080×1920 세로 실제 플레이 3장 이상, 3개 모드 포함 | 기존 검증 캡처는 참고 자료이며 제출용 확정본 아님 |
| 선택 화면·메뉴 스크린샷 | 실제 기능을 보여 주는 보조 이미지 | 추후 제출용 캡처 필요 |
| 미리보기 영상 | 선택 사항 | 미제작 |

스크린샷은 320~3840px 범위, 긴 변이 짧은 변의 두 배를 넘지 않아야 합니다. 현재 SM-S938N 원본 1080×2340은 이 비율을 초과하므로 그대로 제출용으로 확정하지 않았습니다. 화면을 왜곡하거나 UI를 잘라내기보다 9:16 표시 환경에서 실제 게임 화면을 다시 캡처하십시오. 디버그 텍스트·알림·광고 크리에이티브를 대표 플레이 이미지로 사용하지 않습니다. 이미지 제작이나 앱 디자인 변경은 이번 요청 범위에 넣지 않았습니다. [공식 이미지·소개 요구사항](https://support.google.com/googleplay/android-developer/answer/9866151).

추가로 개발자 이메일, 웹사이트 URL, 개인정보 처리방침 URL, 배포 국가와 언어별 문구를 소유자가 준비해야 합니다.
